## LLM-first architecture

`JobInterpretation` is a small provider-neutral Pydantic contract shared by Ollama and Gemini. The model returns semantic requirement names, literal quotes, priorities, evidence IDs, reasons, AND/OR components and uncertainty. Code derives counts, scoring keys, evidence-source records, date unions and other report fields. Supported model interpretations, paraphrases and unfamiliar technologies are retained without requiring a technology dictionary match.

The full offer and a source catalog covering employment, projects, education, languages and verified repository attestations are supplied to the model. Original quotes and URL/content fingerprints remain available. Unknown headings and benefits are not removed before semantic interpretation.

Validation checks source/evidence references, objective proficiency and date contradictions, explicit boolean list consistency and obvious non-qualification passages. Explicit optional/preferred wording cannot become a mandatory blocker. Ambiguous priority (including RTB's “Desired experience” section versus inferred mandatory English) remains visible for review. Git/CI and telecom evidence is not downgraded merely because of its location; it does not imply production CD ownership or operator business-process expertise.

Legacy analyses retain a clearly identified source-review path. Existing JSON exports load through optional/default fields; no destructive migration or profile rewrite is needed. The CV factual export boundary remains stricter than semantic matching.
