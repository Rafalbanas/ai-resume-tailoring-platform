# Code of conduct

## Expectations

Be respectful, constructive, and patient in issues, pull requests, reviews,
and other project discussions. Welcome questions and people with different
backgrounds and experience levels. Critique the work rather than the person,
respect privacy, and accept reasonable moderation decisions.

Harassment, threats, discriminatory or sexualized abuse, doxxing, deliberate
publication of private information, and spam are not acceptable. Do not share
someone's CV, contact details, or credentials without their permission.

These expectations apply to project spaces and when representing the project.

## Reporting

For abusive GitHub content, use its **… → Report content** option. Where
available, choose reporting to repository admins; GitHub also provides
[reporting to GitHub Support](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
The options available depend on the content and your account permissions.

For other moderation concerns, contact the repository owner,
[@Rafalbanas](https://github.com/Rafalbanas), in a relevant project thread. If
details need to remain private, open an issue asking only for a private contact
method; do not include the incident, identities, or evidence publicly. There is
currently no dedicated private maintainer inbox for conduct reports. GitHub
private vulnerability reports are reserved for security issues.

## Moderation

The maintainer may request edits, remove inappropriate content, close or lock
discussions, warn participants, or restrict participation based on severity and
repeated behavior. Context and good-faith corrections matter. Requests to
reconsider a decision should provide relevant context without repeating harmful
content publicly. This is a personal project with no guaranteed response time.
